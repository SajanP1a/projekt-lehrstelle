# Projekt Lehrstelle

Eine zweisprachige Website zur Vorstellung von Unternehmen und ihren Lehrstellen.

## Über das Projekt

Mit diesem Projekt möchte ich Unternehmen und ihre Ausbildungsangebote übersichtlich präsentieren. Gleichzeitig dokumentiere ich meine Fähigkeiten in der Webentwicklung und meinen Umgang mit digitalen Werkzeugen und KI.

Die Website ist auf Deutsch und Englisch verfügbar.

## Funktionen

- Übersicht aller vorgestellten Unternehmen
- Individuelle Unternehmensprofile
- Deutsche und englische Inhalte
- Dynamisches Laden der Unternehmensdaten
- Quellenangaben zu den Informationen
- Responsive Design

## Technologien

- HTML
- CSS
- JavaScript
- JSON
- Git und GitHub

## Lokal starten

1. Repository lokal öffnen.
2. Projektordner in Visual Studio Code öffnen.
3. Die Erweiterung Live Server verwenden.
4. `index.html` mit Live Server öffnen.

**Hinweis:** Live Server wird benötigt, damit die JSON-Dateien über `fetch()` geladen werden können.

## Hinweis

Die Unternehmensinformationen dienen der Orientierung. Für verbindliche Angaben zu Lehrstellen sind die offiziellen Webseiten der jeweiligen Unternehmen massgebend.
