# Projektplanung – Projekt Lehrstelle

**Version:** 1.0  
**Status:** In Planung

## 1. Projektvorgehen

Das Projekt wird schrittweise entwickelt. Zuerst entsteht eine funktionierende Grundversion. Anschliessend werden zusätzliche Funktionen integriert und das Projekt veröffentlicht.

## 3. Arbeitsweise

Die Entwicklung erfolgt schrittweise.

Nach jedem Meilenstein wird das Ergebnis überprüft und dokumentiert.

GitHub wird zur Versionsverwaltung eingesetzt. Änderungen werden regelmässig gespeichert und nachvollziehbar festgehalten.

Künstliche Intelligenz wird als unterstützendes Werkzeug verwendet. Die generierten Ergebnisse werden überprüft und bei Bedarf angepasst.

## 4. Erfolgskriterien

Das Projekt ist abgeschlossen, wenn die Anforderungen aus dem Pflichtenheft erfüllt sind und die Website öffentlich über GitHub Pages erreichbar ist.

Die Dokumentation soll den gesamten Entwicklungsprozess nachvollziehbar darstellen.
