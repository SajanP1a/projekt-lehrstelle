# Designkonzept – Projekt Lehrstelle

## 1. Designziel
Die Website soll technologisch, modern und professionell wirken. Das Design unterstützt die übersichtliche Darstellung von Unternehmen und Lehrstellen.

## 2. Designstil
- Technologisch
- Dunkles Erscheinungsbild
- Moderne Gestaltungselemente
- Dezente Animationen
- Klare und übersichtliche Struktur

## 3. Farbgestaltung
- Hintergrund: Dunkelblau (#071426)
- Karten und Inhaltsbereiche: Blaugrau (#10243D)
- Akzentfarbe: Blau (#2463A5)
- Text und Kontraste: Weiss (#FFFFFF)

## 4. Typografie
Verwendung einer modernen, gut lesbaren Schrift wie Inter oder Roboto. Für technische Beschriftungen kann JetBrains Mono eingesetzt werden.

## 5. Navigation
Die Navigation befindet sich am oberen Rand der Website. Sie enthält die wichtigsten Seitenbereiche und ermöglicht eine einfache Orientierung.

## 6. Seitenaufbau
### Startseite
- Navigationsleiste
- Projektvorstellung
- Übersicht aller Unternehmen
- Unternehmenskarten
- Footer

### Unternehmensprofil
- Unternehmensname und Logo
- Unternehmen
- Interessante Fakten
- Die Lehrstelle
- Was macht diese Lehrstelle einzigartig?
- Arbeitsumfeld
- Quellen

## 7. Animationen
- Dezente Hover-Effekte
- Leichte Bewegung von Karten
- Sanfte Übergänge bei Buttons
- Dezentes Einblenden von Inhalten

## 8. Responsive Design
Die Website wird für Computer, Tablets und Smartphones optimiert.

## 9. Technische Umsetzung
- HTML für die Struktur
- CSS für Gestaltung und Animationen
- JavaScript für Interaktionen und Navigation
- JSON für Unternehmensdaten
- GitHub Pages für die Veröffentlichung

## 10. Designgrundsätze
- Einheitliches Erscheinungsbild
- Gute Lesbarkeit
- Klare Navigation
- Wenig visuelle Ablenkung
- Einheitliche Darstellung aller Unternehmensprofile
